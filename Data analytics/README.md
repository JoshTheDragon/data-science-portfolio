## Getting Started

### Prerequisites

- Python 3.8+
- pip or uv package manager

### Installation

1. Clone the repository:
```bash
git clone https://github.com/JoshTheDragon/data-science-portfolio.git
cd data-science-portfolio
```

2. Install dependencies (for individual projects, check their respective directories):
```bash
pip install -r requirements.txt
```

### Running the Projects

Each project has its own directory with specific instructions. Navigate to the project folder and follow the setup instructions there.
